# ModernStillness — Cinematic WebGL Environment

[Live demo](https://modernstillness.nourtin.com/) · [Full case study](https://nourtin.com/pages/Subpages/modernstillness-cinematic-webgl.html) · [Nourtin](https://nourtin.com/)

## Purpose

A browser-based cinematic environment combining professional 3D composition and lighting with interactive frontend engineering.

## Main systems

- Three.js / WebGL scene with baked lighting and HDR reflections.
- Intro video with skip controls and coordinated scene startup.
- Dust particles and instanced falling leaves.
- Fire video texture, emissive surfaces, and ambient audio.
- Interactive information panels and responsive UI.
- Runtime FPS monitoring and adaptive pixel ratio.
- Static-server workflow without a build step.

## Engineering focus

The project explores the balance between visual atmosphere, loading behavior, rendering cost, and user control. Baked assets reduce runtime lighting cost; adaptive quality helps accommodate different devices. Media playback depends on browser support and user interaction.

## Repository scope

This is a public case study, not the complete application source or an asset distribution. The live experience and visual case study show the result.
